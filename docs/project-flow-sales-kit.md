# 業務特化MVP｜営業・提案キット

## 提供価値

既存の管理サービスでは機能が多すぎる、表計算では更新漏れや引き継ぎが起こる、といった小規模業務に対し、必要な操作だけを残したブラウザ型の管理ツールを設計・制作します。

「既存サービスの完全複製」ではなく、参考にしたい操作や画面を確認したうえで、依頼者の業務に必要な部分を独自の画面・コードで実装します。

## サービス名の候補

- Excel・スプレッドシート業務を小さなWebツールにします
- 既存サービスを参考に、必要機能だけの業務管理MVPを作ります
- 顧客・案件・予約・在庫などの社内管理画面を試作します

## 対象になりやすい相談

- Excelやスプレッドシートを複数人で更新している
- 顧客、案件、期限、対応履歴が複数の場所に分散している
- 市販サービスには不要な機能が多く、費用も合わない
- 本開発の前に、操作できる画面で要件を確かめたい
- 現場独自の受付、集計、確認フローをブラウザ化したい

## 初回提案の範囲

- 現状業務と課題の整理
- 主要1〜3画面の設計
- 登録・編集・一覧・検索などの基本操作
- デモデータを使った動作確認
- スマートフォン表示
- 簡易マニュアル

認証、外部サービス連携、決済、機密情報の保管、複数権限、大量データ移行は、初回ヒアリング後に別途見積もります。

## 提案前に確認すること

1. 現在は何を使って管理しているか
2. 誰が、いつ、どの端末から操作するか
3. 必ず登録したい項目は何か
4. 最も時間がかかっている操作は何か
5. 出力・集計・通知で必要なものは何か
6. 個人情報や機密情報を扱うか
7. 参考にしたい既存サービスのどこが使いやすいか
8. 初回納品で絶対に必要な機能は何か

## 提案文テンプレート

はじめまして、京介と申します。

ご相談内容を拝見し、単に既存サービスをそのまま再現するのではなく、実際の業務で使う操作に絞った管理ツールとして整理すると、導入後も扱いやすいと考えました。

まずは、現在の管理方法・利用者・必須項目・最も時間がかかっている作業を確認し、主要画面と操作の流れを共有します。そのうえで、登録・編集・一覧・検索など、初回運用に必要な範囲からMVPとして実装します。

自主制作の「案件フロー管理」では、顧客・案件・期限・次の行動を一画面へまとめ、ダッシュボード、5段階の進捗ボード、追加・編集、検索、期限超過表示、CSV出力まで実際に操作できる形で制作しています。

参考サービスがある場合も、名称・ロゴ・素材・画面をそのまま転用せず、必要な操作を確認したうえで独自に設計します。未確定部分は着手前に一覧化し、認識を合わせてから進めます。

よろしければ、現在お使いの表や画面と、「最低限ここまで動けばよい」という範囲をお聞かせください。

## 短文営業テンプレート

Excelや既存サービスで管理しにくい業務を、必要機能だけの小さなWebツールへ整理・試作します。顧客・案件・期限管理の操作デモがあり、登録・編集・検索・進捗変更・CSV出力までご確認いただけます。参考画面がある場合も、必要な操作を整理して独自設計します。

## 表現上の注意

- 「同じものを完全にコピーできます」と断定しない
- 他社のロゴ、文章、画像、ソースコードを流用しない
- 自主制作と受託実績を混同しない
- 認証やデータベースが未実装のデモを、本番運用可能と説明しない
- AI利用の有無より、成果物の確認方法、品質、秘密保持、利用規約への適合を優先する
