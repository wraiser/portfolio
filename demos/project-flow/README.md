# 案件フロー管理｜業務特化MVP

顧客・案件・期限・次の行動が複数の表やメモに分散する状況を想定し、必要な情報を一画面へ集約した自主制作デモです。

既存の汎用管理サービスをそのまま複製するのではなく、小規模事業者や少人数チームが「次に何をすべきか」を判断しやすい範囲へ機能を絞り、画面と操作を独自に設計しています。

## 実装済み

- 進行中件数、期限、見込金額、完了率のダッシュボード
- 5段階の案件ボード
- ドラッグ＆ドロップによる進捗変更
- 案件の追加・編集・削除
- 顧客名、優先度、金額、期限、次の行動、メモの管理
- 案件名・顧客名の検索と優先度フィルター
- 期限超過と7日以内の対応の可視化
- 表示中データのCSV出力
- `localStorage`によるブラウザ内保存
- デスクトップ・スマートフォン対応

## このデモの範囲

案件獲得時の初期ヒアリングや、短期間のMVP制作を想定したフロントエンド検証版です。画面上で触れる機能は実際に動作しますが、以下は本番導入時に要件を確認して追加する項目です。

- ユーザー認証と権限管理
- クラウドデータベースへの同期
- ファイル添付
- メール・カレンダー通知
- 操作履歴とバックアップ

未実装の機能を実装済みとして見せないため、デモデータはブラウザ内にだけ保存されます。

## 使用技術

- HTML5
- CSS3
- Vanilla JavaScript
- Web Storage API
- Drag and Drop API
- Blob API（CSV出力）
